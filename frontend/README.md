# Meu Fluxo — front-end React

Base inicial do aplicativo Meu Fluxo, feita com React e Vite. A interface foi dividida em componentes React e usa dados de exemplo. O cadastro de lançamentos, a persistência, o PWA e a integração com o backend Python serão implementados nas próximas etapas.

## Executar

No terminal aberto nesta pasta:

```bash
npm install
npm run dev
```

Abra o endereço local mostrado pelo Vite. Para testar uma alteração, edite `src/App.jsx` e salve o arquivo. Para verificar uma versão de produção, execute `npm run build`.

O protótipo original permanece na pasta `dist` da raiz do projeto, separada desta pasta `frontend`.
